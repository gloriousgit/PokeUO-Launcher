# PokeUO Launcher

**PokeUO** is a Pokemon-themed Ultima Online shard.

## Play

1. Download **[PokeUOLauncher.exe](https://github.com/gloriousgit/PokeUO-Launcher/releases/latest/download/PokeUOLauncher.exe)**.
2. Run it and press **INSTALL**. It downloads everything the game needs (about 2.5 GB, 6 GB on disk) into
   `%LOCALAPPDATA%\PokeUO` - no admin rights, nothing else to install.
3. Press **PLAY**. Start the launcher every time you play: it updates the game and connects you to the server.

Windows 10/11 (64-bit). Windows may warn about an unknown publisher the first time - choose *More info* -> *Run anyway*.

## What's in this repo

- `launcher.json` - what the launcher installs and which server it connects to.
- Releases - the launcher itself and the files it downloads (game data, PokeUO content, the ClassicUO-based
  game client, the world map).
